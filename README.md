# RGB-light-Controller-Remote 
<div align="right"><i>-by Nayan Ag</i></div><br>
Designed a crudely reverse engineered PCB of a standard RGB light controlling remote. The schematic has 0 ERC but there are DRC issues in PCB editor which I will resolve from time to time. This design is purely a personal project to determine my reverse engineering skills. 
<br> 
The final pcb is improvised a lot and there are additional vias placed whenever necessary.
